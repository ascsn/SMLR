# Software Package Development Agents

Use these agents when turning scientific research code into a maintained Python package: defining package boundaries, stabilizing APIs, adding tests, shaping command-line workflows, curating artifacts, and preparing packaging metadata.

Agents in this category:

- `package-architect`
- `api-stabilizer`
- `test-engineer`
- `cli-workflow-engineer`
- `dependency-artifact-curator`
- `packaging-auditor`
