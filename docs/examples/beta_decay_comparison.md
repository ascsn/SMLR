# Beta Decay Backend Comparison

This comprehensive example compares SMLR's emulation backends using realistic
nuclear β-decay strength function data for the Ni-80 nucleus.

Key Finding: The Parametric Matrix Model (PMM) significantly outperforms
regression-based emulation for extrapolation and sum rule preservation, while regression is faster for training.

## Physical Background

### Gamow-Teller Strength Functions

β-decay transitions are governed by the Gamow-Teller (GT) operator:

$$\hat{O}_{GT} = \sum_k \sigma_k \tau^{\pm}_k$$

The strength function $S(E)$ encodes the nuclear matrix elements:

$$S(E) = \sum_f |\langle f | \hat{O}_{GT} | i \rangle|^2 \delta(E - E_f)$$

### Half-Life Integration

The β-decay half-life is computed from:

$$\frac{1}{t_{1/2}} \propto g_A^2 \int_0^{Q} S(E) f(Q-E) \, dE$$

where $f(E)$ is the Fermi phase-space factor.

### Pairing Parameters

The nuclear structure depends on pairing correlations:

- **α (isoscalar)**: Affects overall collectivity and resonance energy
- **β (isovector)**: Controls neutron-proton correlations and fragmentation

## Key Insights

### When to Use PMM

- Extrapolation: PMM's physics-based structure generalizes better
- Sum rules: Eigenvalue structure preserves spectral moments
- Interpretability: Matrix elements have physical meaning
- Sparse training: Works with fewer samples

### When to Use Regression

- Speed: Much faster training, especially for large datasets
- Simplicity: Fewer hyperparameters to tune
- Interpolation: Competitive accuracy within training region
- High dimensions: Scales better with many parameters

## Physical Interpretation

### Sum Rule Preservation

The Ikeda sum rule for GT strength:

$$S_- - S_+ = 3(N - Z)$$

PMM preserves this because the total strength is encoded in the 
eigenvector normalization, which is preserved under parameter variation.

### Extrapolation Behavior

PMM uses the structure:

$$M(\mathbf{p}) = D + \sum_i (p_i - p_0^{(i)}) S_i$$

This **linear** dependence on parameters allows smooth extrapolation,
while regression can produce unphysical poles outside the training region.
