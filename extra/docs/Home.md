# Home

Welcome to **SMLR** — Surrogate Models for Linear Response.

This repository provides emulators and workflow tools for QRPA-based
simulations of dipole polarizability and beta-decay strength data.

## First-release scope

The `0.1.0` release is focused on paper reproduction, two-parameter
linear-response spectral emulation, the diagnostics used for the paper, and
the documentation needed to install and run those workflows.

Supported observables:

- Dipole polarizability
- Beta-decay half-life

Supported backend:

- TensorFlow

Code outside the documented `smlr` package commands should be considered
research or archival code for this release. Archival code will either remain
available through the git history or be moved to an archive branch.
